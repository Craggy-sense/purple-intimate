# Purple Intimate Lingerie — eCommerce Storefront

A luxury, high-conversion eCommerce storefront for **Purple Intimate Lingerie** located at **Shop MF18, The Circle Mall, Timau Road, Kilimani, Nairobi, Kenya**.

Inspired by the body-positive, high-converting layout of **LadyLuck Shapewear** and elevated with a crisp, radiant white aesthetic with royal violet and warm amber accents.

## 🚀 Instant Deployment with GitHub Pages

You can host this website live for free in 30 seconds using GitHub Pages:
1. Go to your repository on GitHub: `https://github.com/Craggy-sense/purple-intimate`
2. Click on **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Your website will be live at `https://craggy-sense.github.io/purple-intimate/`!

---

## 💻 Local Development

Run with any static HTTP server (e.g. Python):
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
